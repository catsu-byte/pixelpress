# PixelPress

Compress, resize, and convert images without uploading them anywhere.

## Why it is useful

Image files are processed with the browser Canvas API, entirely on the user's device. PixelPress is ideal for quickly preparing images for websites, email, and social media.

## Features

- JPG, PNG, and WebP input
- Resize with locked aspect ratio
- WebP, JPG, and PNG output
- Live file-size estimate
- Drag and drop
- Offline, installable PWA
- No uploads, accounts, analytics, or dependencies

## Run locally

```bash
python -m http.server 4174
```

Open `http://localhost:4174`.
